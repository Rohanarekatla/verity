# data/

Static reference data and test fixtures — no code, owned jointly by
whoever needs to add to it.

- [`wcag/`](wcag/) — WCAG 2.2 success criteria as structured data.
- [`apg-contracts/`](apg-contracts/) — YAML interaction contracts for
  ARIA design patterns (dialog, menu, tabs, combobox, disclosure).
- [`fixtures/`](fixtures/) — paired good/bad HTML test files used by
  both the Node and Python test suites.
