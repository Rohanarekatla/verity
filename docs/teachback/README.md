# docs/teachback/

Sunday teach-back notes, one file per week: `YYYY-WW.md`.

**The listener writes the notes, not the teacher.** Each engineer
teaches the other what they built that week; the person listening
writes it up. A teacher summarising their own work proves nothing —
they already understood it. A listener producing coherent notes proves
the transmission actually happened.

Where the notes are thin or wrong, that's exactly the area to revisit
the following week.

Suggested shape:

```markdown
# 2026-W02

## A → B: <what A built>
*Notes written by B*

## B → A: <what B built>
*Notes written by A*

## Thin spots to revisit
```
