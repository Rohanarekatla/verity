## A → B: element capture and the Spike A corpus

*Notes written by B (Nikhil)*

**What Rohan built (A2.1, A2.2, A2.3):**

`node-worker/crawler/elements.ts` takes a CSS selector and produces a cropped
PNG of that one element, plus its rectangle in two different coordinate
systems at once:

- **CSS pixels** — what `getBoundingClientRect()` and every CSS selector talk
  in. Device-independent.
- **Device pixels** — what the PNG is actually made of. On a 2× Retina
  display a 100×20 CSS-pixel button is 200×40 real pixels in the image.

Both are stored, along with the `device_pixel_ratio` they're related by. The
reason is that the two consumers disagree: the vision model looks at the PNG
and reasons in device pixels, while the contrast maths has to map back to a
CSS selector. If we stored one and multiplied later, every consumer would
have to remember to do it, and the one that forgets produces a box that's
off by a factor of two.

`measure()` adds `window.scrollX/scrollY` back onto the rect, because
`getBoundingClientRect()` is relative to the *viewport* but the full-page
screenshot is relative to the *page*. Without that, anything below the fold
is measured in the wrong place.

`captureElement()` returns `null` instead of throwing when it can't shoot an
element — invisible, zero-size, detached, off-screen, or an axe selector we
can't re-parse. A missing element is an ordinary thing on a real page, not a
reason to fail an entire render.

`imageInventory()` finds every image-bearing element via four routes:
`<img>`, `<canvas>`, inline `<svg>`, and CSS `background-image`. The last one
is the interesting one — text over a CSS background image is exactly where
contrast failures hide, and it's the case axe-core marks `incomplete`.

`render.ts` populates `element_screenshots` for every image at render time;
`static/axe.ts` adds crops for the text nodes axe marks `incomplete`, because
those aren't known until axe has actually run.

The corpus (A2.3) takes 30 clean pages, applies 3 injectors, and produces
labelled cases with known ground truth. Of 197 structurally valid cases,
**117 are confirmed usable** — the rest were injected but the resulting
defect wasn't actually detected, so they can't be scored.
