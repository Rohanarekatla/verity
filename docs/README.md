# docs/

Architecture Decision Records and other design notes that don't belong
in code comments or a directory `README.md`.

- [`adr/`](adr/) — one file per non-obvious decision: the options
  considered, the choice made, and why. Written when the decision is
  made, not reconstructed later — see [`adr/0001-polyglot-json-rpc-over-stdio.md`](adr/0001-polyglot-json-rpc-over-stdio.md)
  for the format to follow.

When you're about to revisit a past decision, read its ADR first. It
usually already records the alternative you're considering and the
reason it lost.
