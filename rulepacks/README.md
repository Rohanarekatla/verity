# rulepacks/

Custom rule definition packs (`.verity-rule.yaml`) — a way to add
project-specific accessibility rules on top of the built-in WCAG/ACT
checks without forking the engine.

- [`fixtures/`](fixtures/) — required passing and failing HTML for
  each rule, so a rule pack can't be merged without proof it fires on
  the bad case and stays silent on the good one.

Not yet populated.
